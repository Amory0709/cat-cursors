猫标 Cat Cursor - macOS 安装包
================================

安装步骤（约 10 秒）：

1. 若尚未安装 Mousecape，请先下载：
   https://github.com/alexzielenski/Mousecape/releases

2. 双击「Install Cat Cursor.command」

3. 按提示完成安装

4. 首次使用请在 Mousecape 菜单执行：
   Install Helper Tool
   （这样重启后光标会自动恢复）

说明：
- macOS 不支持像 Windows 那样原生替换光标，需要 Mousecape。
- 部分 App（如 Terminal）可能仍显示系统默认光标。
