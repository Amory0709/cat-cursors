猫标 Cat Cursor - 请先阅读

推荐安装方式（不需要运行脚本）：
1. 安装 Mousecape-swiftUI：
   https://github.com/sdmj76/Mousecape-swiftUI/releases/latest
2. 先打开 Mousecape，把 Cat-Cursor.cape 拖进窗口，或用 Import 导入。
3. 确认导入，选中「猫标 Cat Cursor」，点击 Apply / 应用。
4. 在 Safari 打开 Cursor Test.html，检查箭头、链接、文字、抓取及缩放区域。
5. 恢复默认：Mousecape 菜单 File > Reset System Cursor，或 Cmd+R。

导入不等于应用。安装脚本只请求打开主题，不会报告「已成功应用」。
两个 .command 是可选的未签名导入助手；被 macOS 拦截时，跳过脚本即可。
不要关闭 Gatekeeper、递归清除隔离属性，也不要删除整个 Mousecape 配置目录。
SHA256SUMS 用于发现文件损坏，不是数字签名或安全担保。

默认 32pt，包含 1x/2x 无损 PNG 表示，动画最多 24 帧。
保留一轮动画时长，但长动画会减少显示姿势，不承诺保留原始帧率。
没有合适美术的禁止、精确十字、复制和斜向缩放等角色保留系统原样。

导入后仍无变化：
- 确认选中的是新导入主题并点了 Apply，动画开关没有关闭。
- 只在 Dock 生效：按管理器官方说明检查系统的自定义指针颜色。
- 某些应用有自己的光标；请同时在 Finder 和 Safari 测试。
- 安全权限只按管理器和 macOS 的实际提示处理，不盲目放行。
- 问题反馈请附 macOS 版本、芯片、管理器版本、发生在哪一步及日志/截图。
