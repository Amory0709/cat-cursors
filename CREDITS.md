# Credits and platform lineage

## Windows original: HappyCadogt's 猫标 / Cat Cursor

All original cat artwork and animation were created by **HappyCadogt**, Bilibili UID **406949928**. This macOS port is not the original Windows project.

- Original creator: https://space.bilibili.com/406949928
- Original showcase, 「加载中」的猫标: https://www.bilibili.com/video/BV1S2itBHEJH/
- Windows downloads: follow the creator's published instructions on Bilibili. This repository does not claim an independently verified Windows GitHub repository or redistribute a Windows installer.

## GNU/Linux source port: Tseshongfeeshur / Ryan

The PNG/config sources used here originate from **Tseshongfeeshur/cat-cursors**, maintained by **Tseshongfeeshur (Ryan)**:
https://github.com/Tseshongfeeshur/cat-cursors

Its README identifies the Windows original and describes its own GNU/Linux/XDG port. Please do not label this Linux repository as the Windows original. The original `Copyright (c) 2025 Ryan` MIT license text is retained unchanged.

## macOS conversion: Amory0709

https://github.com/Amory0709/cat-cursors

This repository maintains the macOS converter, role mappings, validation, packaging, and installation guidance. `scripts/build-release.ps1` runs the macOS package builder on a Windows host; it is NOT a Windows cursor installer.

## Cursor manager

Mousecape-swiftUI by sdmj76, derived from Alex Zielenski's Mousecape:
https://github.com/sdmj76/Mousecape-swiftUI

Install the manager from its own official releases. Its executable and source are not bundled in this package. Compatibility references are listed in `docs/VALIDATION.md` in the repository.
